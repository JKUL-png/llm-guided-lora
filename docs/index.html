Does It Help When an LLM Chooses Where to Train?

A frontier model diagnosed why a small model gets stuck in loops, then chose which layers to train to fix it. We trained the same fix in random layers and in layers picked by a cheap rule, and compared.

JKUL · November 2026
Paper by Juan José Giraldo Márquez and Juan José Gómez · Read the paper (PDF) · Code and data

TL;DR

Opus did not beat random layers or a cheap rule. Every adapter fixed the loops, but on MATH none of them beat simply turning thinking off. Exploratory results hint that the place matters. The place seems to matter, but Opus did not find a better one than chance.

The question

In part 1 we looked at Qwen3.5-0.8B, a small reasoning model that loops: in thinking mode, 92.2% of its responses use up all 32,768 tokens without answering. A published weight edit fixes much of this, and so does simply turning thinking off.

Here we keep the fix fixed and ask about the place. The fix is a LoRA adapter, a small trainable patch, trained on 388 examples that show the model leaving a loop and answering. The place is which 4 of the model's 24 layers the patch trains. Claude Opus investigated the model with measuring tools and chose four layers. Does a model that diagnoses the problem choose better than chance?

The design

Six ways of choosing the layers, four adapters each. Every adapter has exactly 2,654,208 trainable parameters (4 \times 48 = 24 \times 8, layers times rank), the same data, the same steps and the same learning rate. Only the layers change.

  • (b) Opus, informed. A fresh Claude Opus session per seed, isolated, with tools to probe and switch off layers, a fixed budget, and context about the problem. It never saw an evaluation problem.
  • (c) Random placebo. Four layers drawn before any diagnosis.
  • (d) Gradient rule. The four layers with the largest gradient norm, computed once on the untrained model.
  • (e) Sweep rule and (f) Opus reading the sweep. The system switches off each layer in turn and measures how much the model wants to close its thinking. A fixed rule picks the top four; separately, Opus reads the same table and picks four.
  • (a) All 24 layers at a lower rank, as a reference.

The main test, (b) against (c) and (d), was written down before any evaluation, in a plan kept in a local git repository. We call that pre-specified, because the repository has no external timestamp. Several later analysis choices were made after seeing results, and the paper lists them.

Opus did not beat random layers or a cheap rule

On MATH, Opus's layers scored 54.0%, random layers 55.5% and the gradient rule 51.2%. The differences, −1.5 and +2.8 points, are well inside the noise (Holm-corrected p = 0.69 for both). The pre-specified criterion for "guided wins" was not met.

A tie is not proof of equality. With four adapters per arm, an Opus advantage of up to +5.8 points over random layers, or +10.8 over the gradient rule, would have gone unnoticed. But nothing points that way: retraining the same 24 layers with another seed already moves the score by 13 points.

Against turning thinking off, and against the published edit

Two cheap references sit in every comparison: the original model with thinking turned off, and p50c, the published weight edit from part 1, with thinking on.

  • MATH: no adapter beats turning thinking off (51.8%). The closest is the sweep rule, at +6.8 points [−0.5, +14.2], which does not survive correction. p50c scores about the same as thinking-off (51.2%), but still hits the limit 29.2% of the time.
  • GSM8K: every adapter beats turning thinking off, by +10.0 to +12.8 points. But so does p50c, and the adapters tie with it.
  • IFEval: no adapter differs from turning thinking off, and all are below p50c, by 6.0 to 12.5 points. That gap holds up for three of the six arms.

Training 2,654,208 parameters gave, on MATH, a result we cannot tell apart from flipping one generation option.

Exploratory The place seems to matter

These analyses were chosen after seeing the data. Read them as hints, not findings.

  • One rule beat another. The sweep rule scored +7.2 points above the gradient rule [0.0, +14.5]. Both use the same layers in every seed, and the gap shows up in each one. The sweep rule was also picked as the best arm on these same data, so this number is inflated.
  • Opus reading the sweep did not beat the sweep rule reading the same table: −6.5 points [−14.0, +0.5].
  • Clean answers vary a lot. Some adapters close their thinking, keep reasoning, and close again. Counting responses that close exactly once and stay under the limit, arms range from 57.0% to 81.2%. Opus's layers have the lowest share: −20.8 points against random layers [−38.2, −1.8]. Even the four random draws differ widely.

Limitations

  • Four adapters per arm, each group of layers trained once. Our intervals try to count that, but with four units they are rough.
  • Some analysis choices came after seeing results: the correction families, the interval we call primary, the comparisons with p50c and everything marked exploratory.
  • Reduced scope. A planned second task (teaching facts about a fictional company) was dropped after seeing MATH, and Opus's layers were never evaluated at temperature 1.0.
  • No control for the data. Every adapter uses the same examples, so we cannot say how much of the fix comes from the training data.
  • Opus had a hint. Its context named the two layers of the published edit, and the four sessions agreed little with each other.
  • One model, one recipe, and 100 problems per task.

The paper lists all of them.
